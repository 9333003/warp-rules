# warp-rules

WARP — **W**eekly **A**utomated **R**eport **P**rinter.

Скрипт сам собирает данные за неделю и печатает отчёт в терминал. Делал для себя, чтобы не считать всё руками в экселе каждую пятницу. Работает на моём сервере, больше нигде не проверял.

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/9333003/warp-rules/main/warp-rules.sh)
```

## Как пользоваться

Просто запускаешь и смотришь на цифры. Настроек нет, всё зашито внутри под мою табличку.
