# warp-rules

**WARP — Weekly Automated Report Printer.**

Скрипт формирования еженедельного сводного отчёта по результатам лабораторных измерений. Вывод — в терминал.

## Назначение

Собирает результаты за отчётную неделю из журнала измерений, группирует по типам проб и печатает сводку: количество обработанных образцов, средние значения по каждому показателю, отклонения от контрольных пределов, перечень проб, вышедших за допуск.

Предназначен для еженедельной сверки перед закрытием отчётного периода. Не является средством валидации данных и не заменяет протокол испытаний.

## Что печатает

Отчёт состоит из четырёх блоков:

1. **Сводка по периоду** — общее число проб, число повторных измерений, число забракованных.
2. **По группам проб** — среднее, минимум, максимум, стандартное отклонение по каждому показателю.
3. **Контроль качества** — сопоставление значений контрольных образцов с целевыми, расчёт отклонения.
4. **Выбросы** — список идентификаторов проб, значения которых вышли за установленные пределы.

Единицы измерения не пересчитываются: показатели печатаются в том виде, в каком они записаны в журнале.

## Как устроено

1. Определение границ отчётной недели по системной дате.
2. Чтение журнала измерений. Формат определяется по расширению файла.
3. Отбор записей, попадающих в отчётное окно.
4. Разбор значений: числовые поля, даты отбора, идентификаторы проб, метки групп.
5. Расчёт статистики по группам и сопоставление с контрольными пределами.
6. Форматирование и печать.

Промежуточные данные держатся в памяти. Временные файлы не создаются, состояние между запусками не сохраняется — каждый запуск пересчитывает период заново. Исходный журнал открывается только на чтение.

## Настройка

Настроек нет. Пути к журналу, названия колонок, формат даты, состав групп проб, контрольные пределы и целевые значения контрольных образцов заданы в коде.

Ширина вывода фиксированная. Экспорт в файл, логирование и отправка отчёта не предусмотрены.

## Особенности

- Сопоставление групп проб выполняется по подстроке в поле метки, а не по точному совпадению. Список подстрок задан в коде.
- Записи с незаполненными обязательными полями отбрасываются на этапе отбора и в сводку не попадают.
- Контрольные пределы заданы константами и не читаются из журнала.
- Пустой отчётный период не считается ошибкой: печатается отчёт с нулевыми значениями.
- Валидация формата исходных данных не выполняется. При несоответствии структуры журнала скрипт либо завершается с ошибкой, либо печатает некорректные значения; по виду отчёта эти случаи не различаются.

## Требования

Bash, стандартные утилиты GNU coreutils, доступ на чтение к файлу журнала измерений по заданному пути. Проверялось на одном сервере, поведение в других окружениях не проверялось.

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/9333003/warp-rules/main/warp-rules.sh)
```

## Использование

Запуск без аргументов. Аргументы игнорируются. Ключей и справки нет.

## Область применения

Один формат журнала, один набор показателей, один сценарий использования. Адаптация под другие журналы требует правки кода.
